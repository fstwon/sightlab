# Code Block

본문 안의 코드. **머리줄(언어 + 복사 버튼)**과 줄 번호가 붙은 코드 영역으로 이루어진다.

## 마크업

```html
<figure class="sl-code-block">
  <figcaption class="sl-code-block__header">
    <span>typescript</span>
    <button type="button" class="sl-code-block__copy">
      Copy <svg aria-hidden="true"><!-- copy.svg --></svg>
    </button>
  </figcaption>
  <div class="sl-code-block__body" tabindex="0">
    <pre class="sl-code-block__code"><code><span class="sl-code-block__line">…</span>
<span class="sl-code-block__line">…</span></code></pre>
  </div>
</figure>
```

| 요소                             | 필수 | 설명                                                                             |
| -------------------------------- | ---- | -------------------------------------------------------------------------------- |
| `<figure class="sl-code-block">` | 필수 | 루트. 바탕 `bg-code`, 모서리 `md`                                                |
| `sl-code-block__header`          | 필수 | 높이 48px. 언어 이름과 복사 버튼 (mono 12)                                       |
| `sl-code-block__copy`            | 선택 | 복사 버튼. 동작(클립보드 복사, 완료 표시)은 앱이 구현                            |
| `sl-code-block__body`            | 필수 | 코드 영역. 긴 줄은 이 영역만 가로로 스크롤. 키보드로 스크롤하도록 `tabindex="0"` |
| `sl-code-block__code` (`pre`)    | 필수 | mono 14/27                                                                       |
| `sl-code-block__line`            | 필수 | 한 줄. 줄 번호는 CSS 카운터로 그려 복사·낭독에 섞이지 않는다                     |

## 상태

| 상태         | 표현                                                                   |
| ------------ | ---------------------------------------------------------------------- |
| 복사 완료    | `sl-code-block--copied` + 버튼 글자 "Copied"와 체크 아이콘 (앱이 바꿈) |
| hover        | 복사 버튼 투명도 0.8 (Figma에 없어 추가)                               |
| 키보드 focus | 복사 버튼·코드 영역에 외곽 링                                          |

## 앱이 할 일

- 글자 색(문법 강조)은 앱이 정한다. 노트 본문은 빌드 때 shiki로 색을 입히고, 줄마다 `sl-code-block__line`을 붙인다.
- 복사 버튼을 누르면 코드를 클립보드에 넣고, 잠시 `--copied` 상태로 바꾼 뒤 되돌린다. 바뀐 상태는 화면 낭독기에도 알린다 (`aria-live`).

## 접근성

- 복사 버튼은 겉모습보다 누르는 영역을 44px까지 넓힌다.
- 코드 영역은 넘칠 때 키보드로도 스크롤할 수 있도록 focus를 받는다.
