# Tag

글의 태그를 표시하거나, 목록에서 태그로 거르는 필터 버튼으로 쓴다.
원본: `@sightlab/ui` `tag.scss` · Figma 02 Components / Tag Badge (node 37:16)

<Controls of={TagStories.Neutral} />

## 마크업

```html
<!-- 표시용 -->
<span class="sl-tag">React</span>

<!-- 필터 토글 -->
<button type="button" class="sl-tag sl-tag--selected" aria-pressed="true">React</button>
```

| 요소                                   | 필수           | 설명                                        |
| -------------------------------------- | -------------- | ------------------------------------------- |
| `<span>` 또는 `<button type="button">` | 필수           | 표시만 하면 `span`, 누를 수 있으면 `button` |
| `sl-tag`                               | 필수           | 루트 클래스. 수정자가 없으면 Neutral        |
| 변형 수정자                            | 선택           | `--brand`, `--accent`                       |
| `aria-pressed`                         | 버튼일 때 필수 | 선택 여부 (`true`·`false`)                  |

## 변형 (수정자)

| 수정자           | 용도               |
| ---------------- | ------------------ |
| (없음)           | Neutral. 기본 태그 |
| `sl-tag--brand`  | 강조할 태그        |
| `sl-tag--accent` | 보조 강조 태그     |

## 접근성

- 겉모습은 높이 32px이지만, 버튼일 때는 보이지 않는 영역으로 누르는 범위를 44px(최소 터치 영역)까지 넓힌다.
- 필터 버튼은 선택 여부를 `aria-pressed`로 알린다. 스타일은 `sl-tag--selected` 수정자로만 건다.
- 글자는 `label` 역할(13/18, 굵기 500)을 쓴다 (Figma 12px에 맞는 토큰이 없어 기존 역할로 통일).
