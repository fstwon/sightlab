# Callout

본문 중간에서 참고·팁·주의·중요 내용을 눈에 띄게 보여 주는 상자. **원형 아이콘 + 제목 + 내용**으로 이루어진다.
원본: `@sightlab/ui` `callout.scss` · Figma 02 Components / Callout (node 77:100)

## 마크업

```html
<div class="sl-callout sl-callout--info" role="note">
  <span class="sl-callout__icon">
    <svg aria-hidden="true"><!-- @sightlab/icons info.svg --></svg>
  </span>
  <div class="sl-callout__body">
    <p class="sl-callout__title">참고</p>
    <div class="sl-callout__content"><p>관련 개념을 함께 확인하면 이해하기 쉽습니다.</p></div>
  </div>
</div>
```

| 요소                                     | 필수 | 설명                                                        |
| ---------------------------------------- | ---- | ----------------------------------------------------------- |
| `<div class="sl-callout">` + 종류 수정자 | 필수 | 루트. `role="note"`로 본문 흐름과 별개인 안내임을 알린다    |
| `sl-callout__icon`                       | 필수 | 32px 원. 안에 종류별 아이콘 SVG(18px) 인라인, `aria-hidden` |
| `sl-callout__title`                      | 필수 | 종류 이름 (참고·팁·주의·중요)                               |
| `sl-callout__content`                    | 필수 | 내용. 문단·목록 등 여러 블록이 올 수 있다                   |

## 변형 (수정자)

| 수정자                | 아이콘            | 바탕·테두리                         | 제목 색         |
| --------------------- | ----------------- | ----------------------------------- | --------------- |
| `sl-callout--info`    | `info.svg`        | `bg-brand-soft` · `action-primary`  | `text-brand`    |
| `sl-callout--tip`     | `check.svg`       | `bg-subtle` · `status-success`      | `text-primary`  |
| `sl-callout--warning` | `exclamation.svg` | `bg-accent-soft` · `accent-default` | `text-primary`  |
| `sl-callout--error`   | `close.svg`       | `bg-accent-soft` · `status-danger`  | `status-danger` |

## 앱이 할 일

- Notion 콜아웃은 `<callout color="…">`로 온다. 배경색으로 종류를 고른다 (blue·purple·gray·기본 → info, green → tip, yellow·orange·brown → warning, red·pink → error).
- Notion의 이모지 아이콘은 쓰지 않고 종류별 아이콘을 쓴다.

## 접근성

- 아이콘은 장식이라 `aria-hidden`으로 숨기고, 의미는 제목 글자(참고·주의 …)로 전한다.
- 색만으로 종류를 구분하지 않는다: 제목과 아이콘 모양이 함께 바뀐다.
- 제목 15px은 맞는 토큰이 없어 `body`(16px)에서 1px를 뺀다. 내용은 14/22.
