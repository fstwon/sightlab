# Button

사용자가 동작을 실행하는 버튼. 원본: `@sightlab/ui` `button.scss` · Figma 02 Components / Button (node 33:2)

## 마크업

```html
<button type="button" class="sl-button sl-button--primary">저장</button>
<a href="/notes" class="sl-button sl-button--secondary">목록</a>
```

| 요소                                     | 필수 | 설명                                                             |
| ---------------------------------------- | ---- | ---------------------------------------------------------------- |
| `<button type="button">` 또는 `<a href>` | 필수 | 루트. 동작은 `button`, 페이지 이동은 `a`                         |
| `sl-button`                              | 필수 | 루트 클래스                                                      |
| 수정자 하나                              | 필수 | `--primary`, `--secondary`, `--ghost`, `--danger`                |
| 아이콘                                   | 선택 | 텍스트 앞뒤에 인라인 SVG (`@sightlab/icons`), 간격은 버튼이 처리 |

## 변형 (수정자)

| 수정자                 | 용도                         |
| ---------------------- | ---------------------------- |
| `sl-button--primary`   | 화면당 하나의 주요 동작      |
| `sl-button--secondary` | 주요 동작 옆의 보조 동작     |
| `sl-button--ghost`     | 강조를 줄인 동작             |
| `sl-button--danger`    | 되돌릴 수 없는 동작에만 사용 |

## 상태

| 상태              | 표현                                                                         |
| ----------------- | ---------------------------------------------------------------------------- |
| 비활성 (`button`) | `disabled` 속성                                                              |
| 비활성 (`a`)      | `sl-button--disabled` + `aria-disabled="true"`, `href` 제거                  |
| hover             | `:hover` (비활성이면 적용 안 됨)                                             |
| 키보드 focus      | `:focus-visible` 외곽 링. 마우스로 클릭할 때는 표시되지 않으며 Tab 키로 확인 |

## 접근성

- 높이 44px로 최소 터치 영역을 충족한다.
- 텍스트 없이 아이콘만 쓰면 `aria-label`이 필수다.
- 상태 스타일은 수정자로만 걸고, `aria-*` 속성은 스타일 선택자로 쓰지 않는다.
- 페이지 이동에는 `<a>`, 그 외 동작에는 `<button type="button">`을 쓴다.
