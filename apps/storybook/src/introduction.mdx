# Sightlab Design System

Sightlab 앱과 실험 앱이 함께 쓰는 공용 디자인 시스템. React 등 특정 프레임워크 없이
**CSS 클래스와 정해진 HTML 구조**로 사용한다.

## 패키지

| 패키지             | 내용                                               |
| ------------------ | -------------------------------------------------- |
| `@sightlab/tokens` | 디자인 토큰 (`--sl-*` CSS 변수)과 글꼴             |
| `@sightlab/ui`     | 컴포넌트별 BEM CSS (`sl-block__element--modifier`) |
| `@sightlab/icons`  | 아이콘 SVG 파일                                    |

## 불러오기

토큰과 컴포넌트 CSS는 앱 진입점에서 **tokens → ui 순서로 한 번만** 불러온다.

```ts
import '@sightlab/tokens';
import '@sightlab/ui';
```

화면 스타일의 값은 역할 토큰(`var(--sl-*)`)만 쓴다. Sass 앱은 출력 없는 API만 필요한 파일에서 쓴다
(`@use 'pkg:@sightlab/tokens/sass'`, `@use 'pkg:@sightlab/ui/sass'`).

## 문서 구성

- **Foundations**: 색·타이포·간격 등 토큰과 아이콘
- **Components**: 컴포넌트별 규칙 문서(마크업·변형·상태·접근성)와 변형·상태마다 하나씩인 스토리

## 규칙

- 변형과 상태는 BEM 수정자로 표현하고, hover·focus는 가상 클래스로 표현한다.
- JS 동작(목차, 모바일 메뉴 등)은 각 앱에서 구현한다.
- 디자인 원본은 Figma `sightlab-design`이며, 값은 Figma를 먼저 바꾼 뒤 반영한다.
