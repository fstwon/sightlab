# Prose

노트 본문처럼 **마크다운에서 만든 HTML**을 감싸 기본 요소(h2, p, 목록, 인용, 표 …)를 꾸민다.
원본: `@sightlab/ui` `prose.scss` · Figma 02 Components / Markdown Content (node 77:37)

## 마크업

```html
<div class="sl-prose">
  <!-- 마크다운 변환기가 만든 HTML 그대로 -->
  <h2 id="context">Context를 분리한 기준</h2>
  <p>…</p>
</div>
```

| 요소                     | 필수 | 설명                                                                        |
| ------------------------ | ---- | --------------------------------------------------------------------------- |
| `<div class="sl-prose">` | 필수 | 루트. 폭은 앱이 정한다 (Figma 데스크톱 720px · 모바일 342px)                |
| 안쪽 HTML                | 필수 | h2, h3, p, a, b, i, code, ul, ol, blockquote, 체크리스트, table, figure, hr |

**다른 컴포넌트와 다른 점:** 본문 HTML은 변환기가 만들어 요소마다 클래스를 붙이기 어렵다.
그래서 Prose만 루트 클래스 아래의 **요소 선택자**(`.sl-prose h2` 등)로 꾸민다. 콜아웃·코드 블록처럼
모양이 복잡한 블록은 앱이 [Callout](?path=/docs/components-callout--docs)·[Code Block](?path=/docs/components-code-block--docs)으로 바꿔 넣는다.

## 요소별 모양

| 요소        | 값                                                                                 |
| ----------- | ---------------------------------------------------------------------------------- |
| 본문        | 16/28 (모바일 15/28), `text-primary`. 블록 사이 16px                               |
| h2          | `h2` 토큰 (28/36, 700), 위 48px                                                    |
| h3          | `h3` 토큰 (20/28, 600), 위 32px. 제목 바로 아래 블록은 12px                        |
| 링크        | `text-brand`, 밑줄                                                                 |
| 인라인 코드 | mono 14, 바탕 `bg-subtle`, 모서리 `sm`                                             |
| 목록        | 16/30, 왼쪽 들여쓰기 24px                                                          |
| 인용        | 바탕 `bg-brand-soft`, 왼쪽 3px `action-primary`, 18/28                             |
| 체크리스트  | 체크박스 18px·모서리 4. 체크됨: 바탕 `text-brand` + 흰 체크, 글자 `text-secondary` |
| 표          | 14/22, 1px `border-default`, 머리 칸 바탕 `bg-subtle`                              |
| 이미지·캡션 | 모서리 `md`, 1px 테두리 / 캡션 14/22 (모바일 13) `text-secondary`                  |

## 접근성

- 제목은 h2부터 쓴다 (페이지 제목이 h1). 목차 링크로 이동할 때 제목이 화면 위에 가리지 않도록 `scroll-margin-top`을 둔다.
- 체크리스트의 체크박스는 읽기 전용(`disabled`)으로 표시만 한다.
- 이미지는 `alt`를 채우고, 설명이 필요하면 `figure` + `figcaption`을 쓴다.
