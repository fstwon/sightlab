# Sightlab Foundations

[Figma Foundations / Editorial Lab](https://www.figma.com/design/KLG3hw257A86HxtigQtNIR/sightlab-design?node-id=23-2) 기준의 공통 디자인 기반입니다.

- `tokens.css`: Primitive / Semantic Light 색상, 글꼴 크기, 간격, 모서리, 레이아웃 너비
- `typography.css`: 타이포그래피 유틸리티 클래스
- `reset.css`: 최소 전역 초기화 및 키보드 포커스 표시
- `shared/ui/Container`: 콘텐츠/본문 최대 너비와 반응형 거터
- `shared/ui/Stack`: 방향 및 간격을 지정하는 레이아웃 프리미티브

이번 단계에서는 Home, Header, Navigation, Footer를 구현하지 않습니다. 기존 실험 미리보기 화면은 임시로 유지합니다.

**검증 필요:** Figma에서 그림자 효과 및 Radius 정확한 수치를 추가로 확인해야 합니다. Radius는 임시값이며, Figma와 일치한다고 확정하지 않습니다. 웹 폰트는 별도 다운로드/설정 없이 설치된 폰트 우선 및 대체 글꼴을 사용합니다.
